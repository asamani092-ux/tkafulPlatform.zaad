## 1) الخلاصة التنفيذية

دُمجت إعادة هيكلة لوحة الإدارة (مراحل أ–ط) في `main` ونُشرت محلياً على واجهة التجربة `:3400` وواجهة البرمجة `:8000`.  
نطاقات الإدارة أصبحت **ثمانية** بدل تسعة: الكفالات داخل بطاقة المشروع، والكادر تحت التقارير.  
أُضيفت نماذج طلبات ديناميكية مرتبطة بمشروع، وتقارير قابلة للعرض والتنزيل.  
**نشر خادم الإنتاج (VPS) لم يُنفَّذ** لعدم توفر مفاتيح الاتصال السري (`DEPLOY_SSH_*`) — المستودع على GitHub محدَّث؛ موقع العميل الخارجي لن يتغيّر حتى يُشغَّل `deploy/deploy.sh` على الخادم.

## 6) كيف يجرّب المقيّم / المطوّر

1. الدخول: البريد `admin@takaful.com` / كلمة المرور `admin123` (حقل المصادقة في واجهة البرمجة قد يُسمّى `username` وقيمته البريد).
2. لوحة الإدارة: `http://localhost:3400/Admin` (تجربة UAT مفعّلة).
3. الطلبات → نماذج ديناميكية → إنشاء وربط بمشروع → فتح الرابط العام `/forms/<slug>`.
4. المشاريع → بطاقة مشروع → رابط بوابة الكفالة إن وُجدت الأداة.
5. التقارير → تبويبات محفوظة / أداء / تقدّم → عرض وتنزيل CSV.
6. الشريط الجانبي: طيّ النطاق يُحفظ بعد إعادة التحميل.
