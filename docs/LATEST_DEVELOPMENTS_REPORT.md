## 1) الخلاصة التنفيذية

دُمج إصلاح واجهة الإدارة ضد **البيانات الخام** (رابط مختصر مطلوب، JSON لإعدادات الأدوات، أكواد حالة/دور إنجليزية، بوابة كفالات منفصلة تُنهي الجلسة) في `main`.

أبرز المخرجات للمستخدم الإداري:

1. إنشاء مشروع/نوع **بدون إدخال رابط مختصر** — يُولَّد تلقائياً من الاسم.
2. إعدادات أدوات المشروع عبر **حقول عربية مُسمّاة** مبنية من مخطط الخادم (لا محرر JSON).
3. **إدارة الكفالات داخل لوحة الإدارة** على المسار `/Admin/projects/:slug/sponsorships` (جلسة مشتركة، بلا خروج منفصل لسقيا).
4. حارس اختبار يمنع عودة أنماط «تسمية أو كود إنجليزي» في صفحات الإدارة وسقيا.

**نشر الإنتاج (VPS):** غير متاح من بيئة الوكيل — لا مسار `/var/www/takaful` ولا أسرار نشر. المستودع على GitHub محدَّث (`origin/main`). النشر المحلي (ترحيل + بناء واجهة + فحص صحة) نجح.

- إزالة حقول الرابط المختصر المطلوبة وعروض المفاتيح/المسارات الخام من شاشات الإدارة.
- حارس اختبار ضد أنماط العرض الخام.

### بوابات التحقق قبل الدمج

- واجهة: 174 اختباراً + بناء إنتاج.
- خلفية: فحص النظام + اختبارات التطبيقات ذات الصلة + مجموعة الرابط المختصر/المخطط.
