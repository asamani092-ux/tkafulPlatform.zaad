# تقرير مختصر — أدوار وصلاحيات منصة تكافل

## ١) المبادئ
- لا تُستخدم مجموعات جانغو؛ الصلاحيات من مصدرين فقط.
- **محور المنصة:** دور على الملف الشخصي + قدرات ثابتة في الكود.
- **محور المشروع:** عضوية مشروع بدور محلي (مشرف مشروع / محرر / مشاهد).
- قدرات المنصة ثابتة في الكود ولا تُعدَّل من الواجهة؛ ما يُضبط من الإعدادات هو **السماح بتسجيل الدخول** لكل دور.

## ٢) أدوار المنصة (ثمانية)

| الدور | الوصف | أبرز الصلاحيات |
|------|--------|----------------|
| مشرف عام | الطبقة الأفقية للمنصة | إدارة المستخدمين، الإعدادات، إنشاء/حذف المشاريع، المتطوعون، الطلبات، اعتماد الكفالات، البث، سجل النشاط، لوحة الكادر |
| مدير | كادر المؤسسة | لوحة الكادر، إنشاء كفالة، اعتماد كفالة — بلا إدارة مستخدمين/إعدادات عامة |
| موظف | كادر تشغيلي | تغذية لوحة الكادر فقط |
| متطوّع | حساب التطوع | التقدّم لفرص التطوع ومتابعة حسابه |
| مستفيد | متلقّي خدمة | بلا صلاحيات إدارة |
| متبرّع | مسار الكفالات | إنشاء كفالة والدفع — لا يعتمدها |
| مورّد | تنفيذ الكفالة | تجهيز الطلب ورفع التوثيق |
| مندوب | ميدان | تسليم الطلب ورفع التوثيق |

## ٣) أدوار عضوية المشروع (ثلاثة)

| الدور داخل المشروع | يستطيع |
|--------------------|--------|
| مشرف مشروع | إدارة أعضاء المشروع وأدواته ومحتواه ضمن مشاريعه فقط — ليس مشرفاً عاماً على المنصة |
| محرر مشروع | تحرير محتوى المشروع دون إدارة الأعضاء |
| مشاهد مشروع | قراءة ضمن نطاق المشروع فقط |

ملاحظة: «مدير مشروع» في التجربة = عضوية **مشرف مشروع**، وليس دوراً ثامناً على مستوى المنصة.

## ٤) من يفعل ماذا (عملي)

| المهمة | من يملكها |
|--------|-----------|
| إعدادات المنصة / المستخدمون / البث / التقارير العامة | المشرف العام فقط |
| إنشاء مشروع أو حذفه | المشرف العام فقط |
| أدوات مشروع مفعّلة | مشرف/محرر المشروع حسب الأداة + العضوية |
| لوحة الكادر | مدير أو موظف (والمشرف العام) |
| اعتماد كفالة | مشرف عام أو مدير |
| تجهيز / تسليم / توثيق كفالة | مورّد أو مندوب (حسب المرحلة) + المشرف العام |
| التقدّم لتطوع | متطوّع |
| تفضيلات الإشعارات | أي مستخدم مسجّل (لحسابه فقط) |

## ٥) بوابة تسجيل الدخول
- لكل دور مفتاح «يُسمح بالدخول» في إعدادات المنصة.
- الافتراضي: مشرف عام / مدير / موظف / متطوّع = مسموح؛ متبرّع / مورّد / مندوب / مستفيد = مغلق حتى يُفعَّل.
- لا يمكن تعطيل دخول المشرف العام.

## ٦) ما ليس صلاحية منفصلة
- لا يوجد دور منصة اسمه «مدير مشروع».
- عضوية المشروع لا تمنح إدارة المستخدمين أو إعدادات المنصة.
- كتم فئة إشعار يخص الحساب فقط ولا يغيّر الدور.
