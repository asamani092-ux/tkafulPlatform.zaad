# دورة حياة مشروع السقيا (1.8) — تفكيك كامل

## 1) الطبقات العامة (بدون دخول)

| الطبقة | المسار | الدور |
|--------|--------|-------|
| هبوط المشروع | `/projects/saqya` | تعريف + أدوات مفعّلة (كفالات، تقارير، خدمات*) |
| تحويل قديم | `/saqya` → `/projects/saqya` | توافق روابط محفوظة |
| خريطة | `/projects/saqya/map` | إن وُجدت خريطة منشورة |
| نموذج سقيا* | `/services/water-supply?project=saqya` | اختياري — يُغلق بـ `VITE_ENABLE_WATER_SUPPLY_FORM=false` |

\* خدمات السقيا = نموذج الماء (قابل للإخفاء دون حذف).

## 2) البوابة التشغيلية (يتطلب دخولاً)

| المسار | من يدخل | الغرض |
|--------|---------|--------|
| `/projects/saqya/sponsorships` | متبرع / مورّد / مندوب / مشرف | دورة الكفالة الكاملة |

**لماذا الدخول؟** كل دور يرى بوابته فقط (دفع، تحضير، تسليم، اعتماد).

## 3) دورة حياة الكفالة (المرحلة 3 — UAT)

```
متبرع: إنشاء كفالة (pending)
    ↓
مشرف: اعتماد → إسناد مورّد + مندوب (assigned)
    ↓
مورّد: تحضير → جاهز (ready) + إشعار مندوب
    ↓
مندوب: تسليم + توثيق (ملف + GPS) (delivered)
    ↓
متبرع: دفع جزئي/كامل (مع رفض تجاوز المتبقي)
    ↓
النظام: اكتمال التمويل → in_progress
```

## 4) نقاط التحكم الإدارية

| الإجراء | أين |
|---------|-----|
| تفعيل أداة الكفالات | `/Admin/projects` → أدوات المشروع |
| رابط التبرع الخارجي | `donation_url` في إعدادات المشروع |
| مراجعة طلبات الماء | `/Admin/requests/water-supply` (إن النموذج مفعّل) |
| إدارة الخرائط | `/Admin/maps` (مشرف عام فقط لإنشاء خريطة جديدة) |
